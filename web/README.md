# web/ — assets hot-linked by kickball.com.au/melbourne

`fonts/` — latin woff2 subsets of the design system's faces, served over
`raw.githubusercontent.com` (CORS `*`, verified 01/08/2026):

| File | Face | Role |
|---|---|---|
| `Display-latin.woff2` | Lilita One | headings, stats, buttons |
| `Body-latin.woff2` | Figtree (variable 300–900) | body, labels, tables |
| `DisplayFat-latin.woff2` | Modak | stickers and poster moments only |

All three are OFL-licensed Google faces; the subsets come from the design
system project and total ~79 KB.

**No player photography belongs in this repo.** It is public git — permanent
history, forkable. The Melbourne page's photos go into Squarespace Custom
Files instead (`/s/<name>`); see `seasons/s5/web/README.md` in the ops
directory for the manifest and the consent record.
